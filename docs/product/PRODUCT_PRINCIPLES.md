# Job Search Assistant — Product Principles

## Local-first

The MVP is designed to work entirely on the user's local machine. Primary user data persists locally.

## Privacy-first

Job applications, resumes, cover letters, notes, networking information, and personal job-search data should remain on the user's local machine by default.

## Simple implementation, scalable architecture

The product should not be over-engineered, while preserving clean boundaries that allow future capabilities to be added without major structural refactoring.

Potential future capabilities identified in the source specification include:
- application timelines
- follow-up tracking
- interview tracking
- recruiter outreach
- networking conversations
- AI-powered job-search assistance
- automated job tracking
- job analysis
- analytics
- cloud synchronization
- multi-user support

These are not part of the original MVP scope.

## Productivity-first UX

The product should make these workflows fast and intuitive:
- add an application
- find an application
- update an application
- open submitted documents
- track networking attempts
- understand job-search progress

The UI should encourage regular use through clarity and low friction.
