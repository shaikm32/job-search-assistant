# Task: Opaque, readable AI Model dropdown surface

## Objective
Replace the near-transparent model listbox background so underlying cards, labels and
controls no longer bleed through the options, while keeping the dark glassmorphism theme.

## Acceptance Criteria
- Listbox background fully obscures underlying text/controls (readable even if
  `backdrop-filter` is unsupported).
- Dark glassmorphism character preserved (sheen + blur + glass border + shadow).
- Light theme also opaque enough (dark text must not bleed through).
- Model names readable; hover/selected/highlighted states clearly distinguishable.
- Border, rounded corners, shadow, `overflow-y: auto` scrolling and `z-index: 20`
  stacking order preserved.
- Positioning logic untouched (`.combobox` anchoring, `top: 100%`, `[data-placement]`).
- No unrelated global styles changed; no new dependencies.
- Relevant tests and builds pass; no commit, no push.

## Root Cause (inspected)
`.combobox [role="listbox"]` used `background: var(--surface)` = `rgba(255,255,255,0.05)`
in dark — a 5% overlay token meant to sit *on top of* an existing glass surface, not to
be a floating surface itself. The dropdown had no opaque layer of its own.

## Workflow
CSS-only visual change, no architectural impact: Developer alone + Orchestrator browser
verification (both themes, open listbox over a text-filled card).

## Relevant Files
- `src/index.css` — dropdown rule (`.combobox [role="listbox"]`, option states) and one
  floating-surface token per theme.
- `src/components/common/ModelSelect.tsx` — read-only; positioning must not change.

## Implementation Status
Complete (CSS-only, `src/index.css`). `ModelSelect.tsx` not modified by this task; no
positioning declaration changed.

- New token `--glass-floating` (dark `src/index.css:61-66`,
  light `src/index.css:135-141`), named after the existing `glass-floating` tier in the
  dark token comment: dark `rgba(13, 17, 34, 0.99)`, light `rgba(247, 249, 255, 0.99)`.
  Comments state the alpha must stay high enough to hide content, because 0.94/0.95 was
  measured to still let card text read through.
- Listbox surface: `background: var(--glass-sheen), var(--glass-floating)`;
  `-webkit-backdrop-filter` + `backdrop-filter: var(--blur-md) saturate(1.2)`
  (enhancement only); `border: 1px solid var(--border-glass)`; `box-shadow: var(--shadow-lg)`.
  Unchanged: `position/top/left/right/margin-top`, `border-radius: var(--radius-md)`,
  `overflow-y: auto`, `min-width: 0`, `z-index: 20`, `[data-placement='above']`.
- Option highlight: accent tint layered over the elevated surface
  (`linear-gradient(180deg, var(--accent-bg), var(--accent-bg)), var(--surface-elevated)`);
  text colour, padding, font-size, truncation and `aria-disabled` styling unchanged.

Correction: initial values 0.94 (dark) / 0.95 (light) still showed the paragraph behind
the open listbox; 0.97 still ghosted; 0.99 is clean in both themes and was adopted.
