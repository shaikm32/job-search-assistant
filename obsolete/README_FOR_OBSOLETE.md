# Obsolete Documentation

The documents in this directory are retained for historical/reference
purposes only.

AI agents and developers MUST NOT use, read, or rely on these documents
when making product, architecture, or implementation decisions.

These documents may contain requirements, constraints, architectural
decisions, or milestone guidance that are no longer applicable.

The active sources of truth are:

- Product requirements → `docs/product/`
- Architecture → `docs/architecture/`
- Implementation-agent guidance → `CODEX_MASTER_PROMPT.md`
- Repository operating instructions → `AGENTS.md`

If an obsolete document conflicts with an active document, the active
document always takes precedence.
